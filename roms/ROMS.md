# Bundled ROMs

Free, open-source homebrew games, redistributed under their own licenses.
Source code for each is available at the links below.

| File | Game | Author | License | Source |
|------|------|--------|---------|--------|
| `thwaite.nes` | Thwaite 0.04 | Damian Yerrick | GPL-3.0 | https://github.com/pinobatch/thwaite-nes |
| `nova.nes` | Nova the Squirrel 1.0.6a | NovaSquirrel | GPL-3.0 | https://github.com/NovaSquirrel/NovaTheSquirrel |
| `croom.nes` | Concentration Room 0.02a | Damian Yerrick | GPL-3.0 | https://github.com/pinobatch/croom-nes |

The emulator itself doesn't depend on these files; they're here so a fresh
clone has something to play and for the browser demo.
